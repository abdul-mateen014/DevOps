# Notes App

This is a simple semester project with:

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js + Express
- Database: SQLite

## Run Locally

1. Install Node.js
2. Run `npm install`
3. Copy `.env.example` to `.env` if you want custom settings
4. Run `npm start`

Open `http://localhost:3000` in the browser.

## Features

- Add note
- View notes
- Delete note
